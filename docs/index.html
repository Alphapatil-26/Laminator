Pointing

    
Four ways to say "this bit"

  

  

    
Pick E

      
One element. You get its rule, its computed styles, the component that rendered it, and any neighbour whose edge misses by a couple of pixels.

    
Text T

      
Select some copy and the exact words come through, so nobody has to guess which sentence you meant.

    
Multi M

      
Click several things. Press M again and they become one comment about all of them.

    
Area A

      
Drag a box. You get the container and everything inside, for when the problem is the arrangement.

    
Freeze P

      
Stops every animation and transition so you can annotate the frame that's actually wrong.

    
Screenshots

      
Attaches a real picture of the element with room around it, so the spacing you're complaining about is visible.

    
Live CSS edits

      
When the rule is writable the popup lists its declarations. Change one, press Enter, and it goes into the file.

  







  

    
The scan

    
It reads your project first

    

      Nothing is hardcoded. On init it walks the repo, works out what you build
      with, finds the stylesheets it may touch, and indexes every selector against the rules
      that mention it. The server proposes candidates; your browser confirms them with
      element.matches().
    

  

  

    
rule
A stylesheet rule paints it. Your agent gets the file, the line, what it declares now, and how many elements share it.

    
utility
Tailwind, or something like it. No rule to edit, so you get the class list and the component name.

    
none
A CSS module, a style block, or CSS-in-JS. You get the classes to search for.

  

  

    
CSS modules stay out of the index. Their class names are hashed when you build, so a
    selector in the browser can't be traced back to source. An anchor there would look right
    and point nowhere.

Safety

    
It stays on your machine

  

  

    
Local only
Binds to 127.0.0.1. Not 0.0.0.0, so nothing on your network can reach it.

    
No dependencies
Zero npm packages. Nothing is fetched at install beyond Laminator itself.

    
Token on writes
Any page you visit can fire a request at localhost. The browser stops it reading the reply, but not sending it, so anything that writes needs a token — and the script carrying that token is only served to localhost.

    
Narrow writes
The write endpoint takes a file, a line, a property and a value. No free-text writes, and the file has to be one the scan listed.

    
Out of your diffs
.laminator/ ships its own gitignore.
